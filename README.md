# Portfólio Maria Clara

Projeto desenvolvido com Next.js, React e TypeScript.

## Requisitos

- Node.js 20.9 ou superior
- npm

## Como executar no VS Code

1. Abra esta pasta do projeto no VS Code (a pasta que contém `package.json`).
2. Abra **Terminal → Novo Terminal**.
3. Instale as dependências:

```bash
npm install
```

4. Inicie o servidor de desenvolvimento:

```bash
npm run dev
```

5. Acesse http://localhost:3000.

## Verificar antes de publicar

```bash
npm run typecheck
npm run build
```

Para executar a versão de produção localmente:

```bash
npm run start
```

## Onde editar

- Conteúdo dos projetos: `src/lib/portfolio-data.ts`
- Páginas e componentes: `src/app/`
- Imagens: `public/project-media/`

**Importante:** mantenha o terminal aberto enquanto estiver usando o servidor local. Para encerrá-lo, pressione `Ctrl + C`.
